# 动态背景的出处

这个目录的模拟和画法照 [ascii-sharks](https://github.com/stackedlol/ascii-sharks) 改写：鱼群（Reynolds 群 + 受惊传递）、
沿跟随式脊柱游的鲨鱼、按格子超采样的栅格化、水纹场，以及鲨鱼、锤头鲨的身体曲线。Plasticine 加的是：通用的身体
（鲸鱼、蝠鲼、老鹰、机械鲨）、地上的小动物（兔子、狐狸、小狗、猫咪，字符画是 Plasticine 自己画的）、只有水流的底、
天上 / 地上 / 赛博三种底、透明底和页面令牌的颜色、字后面压淡、绕开正文、换形象、调速度、暂停。
