# 视频解析

他贴来一个视频链接、想知道一条视频讲了什么、或者要整理抖音收藏时用。

## 怎么用

- 调 `video_parse`，参数 `url` 写链接。抖音、B 站、YouTube、直链 mp4 都行。
- 一条视频要下载、抽音频、转写，几分钟起步。在主线里他等着时，先说一句「在解析，好了告诉你」，开一条后台线去调；
  后台线、定时线里直接调，`wait` 不写（等它做完）。
- 同一条作品解析过就直接拿结果，不重复做。
- 抖音要用他 Mac 上登录着的状态取下载地址：Mac 不在线时会排着，回复里会写「等 Mac 上线」，不要反复调。

## 产出

- 逐字稿（带 [分:秒]）：抖音视频直接在本体这台机器上下载、本地转写，不看标题、配文和自带字幕；别的网站的视频先用
  自带字幕，没有再本地转写。
- 大纲、核心观点、和他兴趣有关的重点。
- 图文作品：读每张图里的文字，结合配文一起总结。

## 改提示词

`prompts/` 里的 summary（总结）、images（读图）两份提示词就是解析时用的，改了下一条就按新的写。这个目录在他的数据里，
程序更新不覆盖。
