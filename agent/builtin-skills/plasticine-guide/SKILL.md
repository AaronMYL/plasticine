# Plasticine 怎么用

这份是给用户答「怎么用」的依据。照这里写的入口和步骤说，用界面上的原名（带「」）；这里没写的，说「不确定，
你可以在界面上找一下」，不要编不存在的按钮。说完怎么做，能替他直接做的就问一句要不要现在做。

## 是什么

Plasticine 是装在用户自己电脑或服务器上的私人 AI 工作台。电脑上用桌面客户端（Mac、Windows）或浏览器，手机上用网页
（可以「装到主屏幕」）。数据在用户自己的机器上。

## 栏目（电脑在最左一列，手机在底栏和「更多」里）

| 栏目 | 做什么 |
|---|---|
| 首页 | 「要你处理」（等他定的事）、「进行中」（后台在做的）、今天的日历和待办、「新的」（做完的结果、来信）、接着读 |
| Plasticine | 和 Plasticine 说话的主线；队友和群组也在这里。手机点「Plasticine」直接是主线，右上角「队友和群组」切换 |
| 消息 | 和别人（联系人、群组）以及他们的 Plasticine 聊天、发任务；邮件也在这里。筛选：联系人 · 群组 · 邮件 · 全部 |
| 任务 | 「进行中」「等你」「定时」「建议」「已结束」「最近删除」 |
| 网页 | 内置浏览器：标签页、书签、历史；登录状态只存在他的电脑上 |
| 阅读 | 信息流（订阅、抖音收藏等）和图书 |
| 笔记 | 他自己写的文字，带 AI 续写、补充建议、整理 |
| 资料库 | Plasticine 写的报告、来信，网页归档，图书笔记，文件，最近删除 |

电脑上右边是对话栏：窗口够宽时停靠成一栏，窄的时候是浮窗；点右上角缩成右下角的圆球。输入框里开「问这一页」，
发出去的话会带上当前这一页的内容。按 ⌘K（Windows 是 Ctrl+K）搜索和跳转。

## 常见的事怎么做

- **让 Plasticine 做一件事**：在主线里直接说。超过一两步的事 Plasticine 会开一件后台任务去做，做完把结果贴回主线，
  「首页 · 新的」和「任务 · 已结束」里也能看到。
- **看做到哪了、叫停**：「任务 · 进行中」点开一件看步骤；可以暂停、停止。也可以直接在主线问「在做什么」。
- **等他定的事**：Plasticine 要花钱、以他的名义对外发、删除、改权限之前会出一张卡问他，卡在「首页 · 要你处理」
  和出卡的那段对话里。朋友 @ 他的 Plasticine、Plasticine 拿不准怎么回时，确认卡出在和那位朋友的聊天里，草稿可以先改再发。
- **定时做事**：在主线说「每周一早上帮我……」，Plasticine 起草一张定时卡，他确认后进「任务 · 定时」；在那里能停、能删。
- **订阅周报、日报**：在主线说要订什么主题，Plasticine 先写一期样刊，他点「开启定时」后按期写，放在资料库。
- **心跳**：Plasticine 每隔一会儿（默认 30 分钟，夜里不跳）看一眼一张短清单（要回复的邮件、日历冲突、等他太久的事、
  朋友的消息、到期的待办……），有事才在主线说一句。清单在「任务 · 定时」的「心跳」那一行里改，也可以对主线说一句话改。
- **记忆**：对 Plasticine 说「记住……」或「忘掉……」；自己看和改在「记忆」（电脑：Plasticine 栏目左下；手机：Plasticine
  页右上「⋯」或「队友和群组」名单底下）。「规则」是他要 Plasticine 一直照做的事。
- **技能**：Plasticine 做某类事的方法。在「技能」页看（入口和「记忆」在一起）；「添加」从商店、一个网址或一个文件夹装，
  装之前能先看它让 Plasticine 怎么做；「新建」说一句想让 Plasticine 学会什么、或挑一件做成过的事，Plasticine 写出草稿，
  改完保存，也可以自己从空白写。随应用提供的不能删，别的可以删。
- **队友**：Plasticine 栏目里「添加队友」，写名字、职责、头像；队友有自己的长期对话，可以直接和它说，也可以在主线 @ 它。
  几位队友可以建成群组，在群里发任务、看分工。
- **联系别人**：「消息」右上角「+」按 @账号 加联系人；聊天里可以发任务卡让对方或对方的 Plasticine 做，交付后验收。
- **用他的电脑**：在电脑上装桌面客户端并登录，「设置 · 系统」里打开让 Plasticine 用这台电脑；之后 Plasticine 能在内置
  浏览器里用他登录着的网站、读他允许的文件。电脑不在线时，这类事会排着等电脑上线。
- **抖音收藏**：在内置浏览器里登录抖音，然后「阅读 · 信息流」里的抖音收藏点「同步」，勾选要处理的再点「处理选中的」。
- **笔记里的 AI**：工具栏上的「续写」「补充建议」两个开关和「整理」；续写的灰字按 Tab 收下。支持直接键入和粘贴 Markdown。
- **换模型**：「设置 · AI」连接提供商（ChatGPT 订阅、Claude、DeepSeek 等），在「各用哪个」里给主线、后台线、心跳、
  翻译等分别选模型；对话输入框下面也能临时换。
- **换外观**：「设置 · 通用 · 外观」选主题（暖纸、石墨、松林、午夜）和跟随系统 / 浅色 / 深色。
- **后台同时做几件事**：「设置 · AI · 同时做几件事」，自动或 1–8。
- **在手机或别的电脑上用**：「设置 · 账号 · 在别的设备上用」给一个网址和二维码；手机浏览器打开后可以「装到主屏幕」。
- **更新**：桌面客户端自己查更新，有新版时窗口上会出更新按钮；也能在「设置 · 系统」里看版本。
- **备份和恢复**：「设置 · 系统 · 备份」，每天自动一份，可以「现在备份」和按对象恢复。

## 设置各段

- 通用：外观、时区、通知、通知记录、装到主屏幕。
- 账号：名字、头像、@账号和密码，在别的设备上用，登录着的设备。
- AI：模型和各用哪个、同时做几件事、工具开关（技能在自己的「技能」页）。
- 隐私与授权：对外可见（哪些记忆、项目、笔记放开给朋友、合作方或所有人，没放开的都是私密）、
  对外授权（哪些事可以自动发出）。
- 浏览器：搜索引擎、登录着的网站、从 Chrome / Safari 导入登录、网页翻译。
- 系统：运行情况、这台电脑和替你动手的电脑、日历和提醒事项（要 Mac）、备份。

## Plasticine 不做的

改自己的代码、iPhone 原生 App、配对码登录、邮件通知，这几样没有，别答应。
