## 放在哪

- `agent/skills/<名字>/` 是正本；需要时用 `npm run skills:sync` 同步到仓库根的 `.claude/skills/<名字>/`（本地副本，不进 git）。
- 2026-11-07《优化清单》第 1 条：Plasticine 装的是打包好的发布版，上下文里没有「改自己」。这两份讲的是写、审
  Plasticine 自己的代码，所以不进服务包、不进运行时的技能目录（改了第 23 条里「给 Plasticine 运行时加载」那半句）。
- 随程序发的内置技能（现在没有）放 `agent/builtin-skills/<名字>/`，打包时再加进 `scripts/packages/package-contents.ts`。
- Plasticine 自己写的、他装的技能（含技能沉淀）在状态目录的 `skills/<名字>/`，更新不碰。模型先读目录元数据，再用
  `skill_read` 加载正文和参考；`skill_write` 修改，带当前版本或新建标记，记录真实执行来源。设置 → AI 里能看到。
- 每个任务固定已经加载的版本；折叠上下文、重启或技能随后更新不会悄悄换掉方法，明确读取新版本后才切换。

## 和设计方案的关系

Skill 说明如何执行已定的产品与界面要求；有冲突时先核对当前要求和源码。视觉细节以 `plasticine-visual` 的方向 I 为准。
