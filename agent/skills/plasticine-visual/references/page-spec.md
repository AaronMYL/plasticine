# 页面规范（11-11 定稿；11-14、11-15 界面统一补）

**这份是 Plasticine 界面规矩的正本**，不管哪个 Agent 来写界面都照它做。设计稿画布、聊天记录只是过程，定下来的都写在这里。
每一页都从下面几样搭出来；不在这里的样式不加。要新样式，先改这份规范，再改页面。新定的规矩当场写进这里，
能自动检查的同时加一条检查进 `npm run check`（已有的检查见文末「自动检查」）。
令牌和字体见 [视觉基础](visual-foundation.md)，动效细节见 [动效决策](motion.md)；和那两份冲突时以这份为准。

## 页面模板

| 模板 | 用在哪 | 结构 |
|---|---|---|
| 列表页 | 任务、消息、资料库、记忆 | 第二栏选范围，主区一列行 |
| 左右分栏 | 抖音收藏、邮件、规则 | 左边列表，右边详情；手机上详情整页打开 |
| 文档页 | 笔记、报告、图书笔记、来信 | 读的宽度（见下面「内容宽度」），标题 + 正文 |
| 封面网格 | 图书馆、信息流里带封面的卡片 | 只给有封面的内容用 |

## 内容宽度（11-15 设计稿 22）

- 两种，跟着主区宽度连续变，都在主区里居中，页头和内容同宽（令牌在 `tokens.css`，`.page` 规则在 `shell/base.css`）：
  - **读的** `--page-read`（一段一段往下读的字：笔记正文、主线和各种对话、信息流、记忆一页、约定、书、邮件、空间文章）：
    主区 970 → 720、1130 → 760、1610 以上 860 封顶。页面加 `.page-read`；铺满型页面里读的那一列直接用 `max-width: var(--page-read)`。
  - **管的** `--page-manage`（列表、卡片、表格：任务、书架、资料库、技能、记忆首页、首页、新标签、项目）：主区 970 → 810、
    1130 → 880、1610 → 1090，最宽 1120。`.page` 默认就是这一种。
  - 铺满的：本来就分栏的（消息、网页、任务看板、笔记）不限宽。
- 两边留 `--page-gutter`：主区 750 以下 24、1050 以上 48，中间跟着变；手机 16。
- 不写死 680 以上的宽度（`ui-layout-rules.test.ts` 守着）；弹框、看图层这类不是页面内容的，在那一行写「例外：原因」。

## 页头

- 标题：页面名，24/32 半粗；后面最多跟一个数（灰色等宽）。不写副标题、说明文字。
- 右侧：一个主操作按钮；其余进「⋯」。「选择」也进「⋯」，不常驻。
- 二级页：标题上方一行面包屑「上一级 /」；手机上用返回箭头代替。
- 名字只写一遍（11-14）：桌面客户端顶上有标题栏，名字和那个数写在标题栏里（`PageHeader` 的 `count`），页里的标题只留给
  读屏，跟着名字的面包屑也不画；本页的操作进标题栏右边（`TitlebarActions`）。网页版、手机照旧画页头。

## 间距

- 页边：见上面「内容宽度」（电脑 24 → 48 跟着主区变，手机 16）。区块之间 28。
- 阶梯只用 4 · 8 · 12 · 16 · 24 · 28 · 40。
- 行平铺，高 48（两行 56），细线分隔；不用卡片包行。

## 组件

| 组件 | 规则 |
|---|---|
| 按钮 | 主按钮（深底）一页最多一个；次按钮描边；文字按钮只用于「撤销」「都留着」这类轻操作；危险操作红字 + 确认 |
| 行 | 前缀（状态符 / 头像 / 图标 20）· 标题 · 一行说明 · 右侧（时间 / 一个按钮 / ⋯） |
| 分段 | 筛选和视图切换都用分段控件，带个数；手机上横滑 |
| 选颜色 | 色板里每个颜色一个色块（`primitives/hue-swatches`），选中描一圈；不用下拉或文字代替 |
| 头像 | 一个字 + 类别色淡底；Plasticine 用自己的标。三档（11-14）：20 行里、菜单、提到人、叠放；28 列表、聊天、来源；40 资料页、详情页头。例外只有图标栏 24、手机底栏 26、对话圆球和编辑里的大预览 52（`avatar-sizes.test.ts` 守着） |
| 弹层 | 电脑：右侧栏或居中对话框；手机：底部弹层。弹框、浮层、抽屉各一个样子，「取消 · 保存」在底部靠右 |
| 菜单 | 一类东西一份操作清单：行尾 ⋯、右键、触屏长按半秒、打开后右上角的 ⋯ 出同一份（`RevealMore` / `ActionItems`）；删除放最后、上面一道线 |
| 搜索框 | 一种（`primitives/search-field`）：高 36、触屏 44；左边放大镜，有字时右边出 ×；Esc 先清空，空了再按交给外面（关浮层、退出查找）。第二栏顶上、浮层里、设置里都用它 |
| 卡片 | 对话里只有两种（`shell/cards.css`）：一行卡 `row-card`（链接、文件、页面快照、对象引用：左边 40 的图或标，右边标题和一行说明）和内容卡 `content-card`（要你定、任务、日程、订阅、队友工作：标题、正文、底部靠右的按钮）；宽都是 560，手机撑满 |
| 图片 | 一套（`primitives/image-grid` + 看图层）：一张整张显示、不裁；多张是 16:9 的一块、最多四格，第四格写「+n」；点开都是同一个看图层（翻页、缩放、下载、打开原文） |
| 等你 | 「等你」是一个记号（`shell/wait-mark.tsx`）：前面一个强调色的点，字是正常字色，带件数写「等你 n」。强调色只做点和描边，不写字、不做按钮底（`accent-rule.test.ts` 守着）；状态色也只染点和符号 |
| 悬停提示 | 只用 Plasticine 自己画的（`data-tip`，`IconButton` 自动带名字），不用系统 `title`（`no-system-title.test.ts` 守着）；整行不挂提示，截断的字该换行就换行；同名的东西靠常显的第二行分开（比如网页历史写站点） |
| 多选 | 资料库那一套（`views/bulk`）：「⋯」里「选择」、⌘ 或 Shift 点、手机长按进入；顶上全选 · 已选 n · 完成，底下浮条放操作；删除不确认，提示条给撤销 |
| 提示条 | 一种：主区底部居中、离底 24（手机在底栏上面）；一句话，最多一个动作（撤销、重试、打开）；5 秒后消失，鼠标停在上面不走；同时只出一条，新的顶掉旧的 |
| 页内横条 | 一种：放在内容最上面，跟着页面走，不浮起来；`--tint2` 浅底、圆角 8；一句话，动作在右边；不用强调色（「连不上服务器，正在重连…」「在另一台设备上读到了第 12 章」） |

| 第二栏 | 252 宽。标题行：栏目名（写栏目本身的名字，不跟着主线、队友改的名字变；`ColumnHead` 的 title 只能是 `sections.ts` 里的栏目名）+ 右边图标按钮（不写字，在哪一页那一个按下去：`--tint2` 底），网页版最右是收起按钮；收起展开是标题栏左边那个按钮或 ⌘\。行尾 ⋯ 鼠标移上去才出、触屏常显。底部不再放入口块（11-15 技能、记忆挪到 Plasticine 栏标题行）。列表还有没滚到的，底部淡出一截 |
| 笔记 | 电脑上第二栏就是笔记列表，主区只放正文；文件夹从列表顶上的文件夹名（「全部 ⌄」）点开，是贴着它的弹层：行尾个数鼠标移上去换成 ⋯（「全部」「最近删除」没有），「新建文件夹」只在最下面一处；手机一层一层进 |
| 对话框 | 浮在主区右侧，拖左边调宽、拖上边或左上角调高（最矮 420，双击上边回整高），宽高记在这台设备；手机全屏 |
| 设置页 | 一种行（左名字、右控件）；例外只有两处要看得到样子：主题是四张小样（左浅右深中间一点强调色，选中描粗、字加重、带勾，手机两张一排），动态背景开着时开关下面一条会动的小样，速度、透明度是滑杆、右边写值 |
| 一直能勾 | 记忆整理、规则搬家、笔记里采用哪几处这类打开就能勾的：和多选同三样零件（`views/bulk/pick-controls.tsx`）——顶上 `PickAll`「全选 · 已选 n」三态，底下 `PickBar` 浮条「已选 n」加这件事的主按钮（「采用这 3 条」「搬过去 9 条」）；没有「完成」。浮层里挑人（建群、编辑群组）主按钮留在浮层底部，旁边写「已选 n」 |
| 滚动条 | 一种，只写在 `shell/base.css`：平时看不见，鼠标在哪一块那一块出一根 4 宽圆头细条（字色 30%，移到条上 8 宽 50%），没有底槽、上下各空 8；浏览器自己的滚动条，右边 10 宽窄边一直留着，出来收起不动排版。别处只能 `scrollbar-width: none` 把横滑的藏起来（`ui-layout-rules.test.ts` 守着） |
| 正在连接 | 打开时连服务端：不到 0.3 秒连上的什么都不出；之后窗口正中 Plasticine 的标（52，慢慢呼吸）下面一行「正在连接…」；8 秒没连上或出错写「没连上 Plasticine：原因」加「重试」（`shell/connecting-screen.tsx`） |

## 加载、空、出错

- 读取三种，各在各的地方：第一次读一页、一个列表用灰条占位（`primitives/page-loading` 的 `PageLoading`，200 毫秒后才淡入，
  不写字）；页里的一小块（评论、全文、附件预览、来路）写一行「正在读…」；按钮做的事在按钮里转圈、按钮不变宽
  （`primitives/busy` 的 `BusyText`，不把按钮字换成「正在读…」，`ui-layout-rules.test.ts` 守着）。
  切页先画上次的内容，新内容到了再换，不把页面往下推。
- 空：一种样子——13/20（`--text-ui`）、第二档字色、左对齐，放在内容该出现的第一行，不上下居中（`.block-empty`，各处
  `*-empty` 也只用这一种字，`ui-layout-rules.test.ts` 守着）；一句话说现在没有什么；能新建的给一个次按钮（加号 + 新建什么）。
  搜不到写「没找到「…」」。
- 出错：一行红字，先说没读到什么、再说原因（「没读到订阅列表：网络断了」），后面跟「再读一次」（11-11 定，11-14 规则表
  保留）。做失败也是一行红字，在做这件事的地方，后面跟「重试」；删除、发送这类用提示条。

## 动效（11-15 设计稿 19）

- 令牌：快 120（悬停、勾选、收起）· 中 180（出现、切换、菜单）· 慢 260（展开高度、第二栏宽度、右侧浮层）；缓动
  `--ease-out` 和带一点弹性的 `--ease-spring`（菜单、开关）。写死时长、缓动的过不了令牌检查器。
- 九种情况各一个样子：
  - 出现：淡入、从下方升 4px，180；一批东西挨个出时每个晚 40。`@keyframes` 里的位移只写 4px（整块滑入的抽屉写例外，
    `ui-layout-rules.test.ts` 守着）。
  - 切换：分段控件的底块从旧那一项滑过去（180，底块画在 `::before`，`shell/segmented-slide.ts`）；新内容淡入升 4px；
    第二栏换栏目一样。
  - 收起 / 展开：高度 260 ease-out（`<details>` 用 `::details-content`），箭头转 90°，180。
  - 第二栏收起展开：宽度 260。菜单：从按钮那个角 0.96 → 1 带弹性，180。右侧浮层：滑入 24 加淡入，260。居中弹框、
    对话框 ↔ 圆球：照现有。
  - 列表增删：新的一行高度和淡入 180，别的行挪位置 180（`FlipList`）。
  - 开关、勾选、悬停：开关带弹性 180，勾 120，悬停底色 120。
  - 消失：只淡出，120。
- 只在位置或状态变化时动；系统开了「减少动态效果」只留淡入淡出（循环的、位移的都去掉）。

## 文案

- 先说结论；平常话；名称、按钮、筛选至少两个字；不写口号和教学段落。
- 统一用词：端到端加密 · 联系人 · 群组 · 队友 · 任务 · 在做 · 已暂停 · 已停止 · 规则 · 最近删除。
- 同一件事一个词（11-14 用词表，`ui-glossary.test.ts` 守着）：关掉（不写关闭）· 删除 / 永久删除 / 移除（不写删掉、彻底删除）·
  取消（不写算了、不用了）· 重试（不写再试一次）· 已选 n（不写选了 n）· 正在读 · 正在保存 · 没读到（不写未能读取、读取失败） ·
  在做（不写进行中，11-17 定：首页、任务页、分工面板、任务卡、工作详情都写「在做」）。
- 时间一种写法，电脑和手机一样（`shell/time-text.ts`）：刚刚 · 5 分钟前 · 09:42 · 昨天 · 周五 · 11-14 · 2025-11-14；
  正文里（来信、期数）写「11 月 14 日」。不另写格式函数。
- 改写示例：

| 旧 | 新 |
|---|---|
| 你的 AI，和朋友的 AI，一起把事做完 | 个人 AI 工作台，可以和联系人的 AI 协作 |
| 看不到内容 | 端到端加密 |
| 正在读… | 灰条占位，不写字 |

## 这一版定下的页面

- **导航**：电脑图标栏 首页 · Plasticine · 消息 · 任务 ｜ 网页 · 阅读 ｜ 笔记 · 资料库；手机底栏不变，
  「更多」里是任务、阅读、资料库、设置。
- **记忆**（11-15 记忆分层，设计稿「Plasticine 记忆分层」）：目录一列，按七层排——总览 → 拿不准的（每条后面写打算放哪一篇）→
  说好的（承诺和授权、主动告诉你两页固定的，一直在，行首一个图标、下面一行写现在的数）→ 你 → 人物 → 项目 → 其他 →
  做事经验（行尾是条数）。
  - 承诺和授权：四段（可以直接做、先问你、先停着、答应你的），段名后面是条数；一行一条（48 高）：行首图标说从哪来
    （对话：聊天里说的；勾：点过「以后直接做」；两竖：停着；✦：Plasticine 答应的），下面一行只写有的（只限哪里），右边是
    哪天说的，行尾 ⋯ 里看出处、修改、先停着、收回；收回的进最下面「已收回 n」，能恢复。对外发送的授权接在四段后面。
  - 主动告诉你：电脑上左右两栏（左：想听的、别提的；右：什么时候、怎么通知、最近），主区窄了和手机上接成一列。
    心跳的开关、多久看一次、不打扰的时段、模型，和「通知哪些事」都是设置页那一种行；他用话说的一行一条、右边是哪天说的。
  - 做事经验的一篇：Plasticine 自己试出来的行前面一个 ✦，文字下面一行是出处（哪天 · 哪件事 ›），改过的再带一行
    「之前：…」；不摆档位。
  - 设置里指到这两页的是一行「记忆 · 承诺和授权 ›」「记忆 · 主动告诉你 ›」（`views/settings/memory-link.tsx`）；
    任务 · 定时里心跳那一行点开直接到主动告诉你，不弹浮层。
  - 搬家记录（`#/memory/layers`，`views/memory/layers-move-page.tsx`）：记忆按层搬过以后的 7 天里目录顶上一条
    「记忆分好层了：搬了 n 条」+「看一下」；记录页按搬去的那一篇分组，一行一条、下面一行小字写原来在哪，行尾「搬回去」
    （电脑上鼠标移到那一行才出，触屏常显），顶上一条横条带「全部搬回去」，最下面只写「没动的 n」。过了 7 天没有这一页。
- **首页**：电脑两栏。左边三段：等你 → 在做 → 新的（报告、来信、昨晚整理的记忆）；右边窄栏：今天（日程）、
  接着读（图书进度）、信息流（几条，带「更多」）。手机合成一列，顺序同左栏再接右栏。问候、日期、数量都用真实数据。
- **阅读**：一个入口。第二栏分四段：信息流（带数）、收藏、图书馆（全部图书 + 在读的书）、来源（每个来源一行带数）。
  信息流单列（读的宽度），每条：来源头像 + 名称 + 时间 / 标题 / 摘要，配图按上面「图片」一套（不截断，X 一条最多四张）；
  条目平铺、细线分隔。
  手机没有第二栏：页头标题「阅读」，下面分段切信息流和图书馆。
- **抖音收藏**：左右分栏。列表带缩略块（播放符号 + 时长）、整理状态（没整理 / 在整理 / 已整理），分段筛选；可多选后「整理这 n 条」。
  详情：一句话结论、原视频 / 讨论、大纲（时间点 + 小标题）、要点。
- **图书笔记**（资料库 / 图书笔记）：文档页。开头一句话总述，每卷一个小节：卷名、一句摘要、回原文入口；不用色条。
- **队友**：页头头像 + 名字 + 职责，右侧「规则 n」；下面在做、最近交付。新建队友对话框：名字、颜色（色块）、
  职责、模型（默认跟主线）。
