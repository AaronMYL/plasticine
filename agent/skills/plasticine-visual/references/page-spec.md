# 页面规范（11-11 定稿）

每一页都从下面几样搭出来；不在这里的样式不加。要新样式，先改这份规范，再改页面。
令牌和字体见 [视觉基础](visual-foundation.md)，动效细节见 [动效决策](motion.md)。

## 页面模板

| 模板 | 用在哪 | 结构 |
|---|---|---|
| 列表页 | 任务、消息、资料库、记忆 | 第二栏选范围，主区一列行 |
| 左右分栏 | 抖音收藏、邮件、规则 | 左边列表，右边详情；手机上详情整页打开 |
| 文档页 | 笔记、报告、图书笔记、来信 | 版心 720，标题 + 正文 |
| 封面网格 | 图书馆、信息流里带封面的卡片 | 只给有封面的内容用 |

## 页头

- 标题：页面名，24/32 半粗；后面最多跟一个数（灰色等宽）。不写副标题、说明文字。
- 右侧：一个主操作按钮；其余进「⋯」。「选择」也进「⋯」，不常驻。
- 二级页：标题上方一行面包屑「上一级 /」；手机上用返回箭头代替。

## 间距

- 页边：电脑 40，手机 16。区块之间 28。
- 阶梯只用 4 · 8 · 12 · 16 · 24 · 28 · 40。
- 行平铺，高 48（两行 56），细线分隔；不用卡片包行。

## 组件

| 组件 | 规则 |
|---|---|
| 按钮 | 主按钮（深底）一页最多一个；次按钮描边；文字按钮只用于「撤销」「都留着」这类轻操作；危险操作红字 + 确认 |
| 行 | 前缀（状态符 / 头像 / 图标 20）· 标题 · 一行说明 · 右侧（时间 / 一个按钮 / ⋯） |
| 分段 | 筛选和视图切换都用分段控件，带个数；手机上横滑 |
| 选颜色 | 色板里每个颜色一个色块（`primitives/hue-swatches`），选中描一圈；不用下拉或文字代替 |
| 头像 | 一个字 + 类别色淡底；Plasticine 用自己的标 |
| 弹层 | 电脑：右侧栏或居中对话框；手机：底部弹层 |

## 加载、空、出错

- 读取：灰条占位，200 毫秒后才淡入；切页先画上次的内容，新内容到了再换，不把页面往下推。
- 空：一句话说现在没有什么，有能做的事就加一个按钮。
- 出错：一行红字说原因 +「再读一次」。

## 动效

- 时长：120 毫秒（悬停、开合），180 毫秒（弹层、侧栏）。
- 只在位置或状态变化时动；系统开了「减少动态效果」就全部去掉。

## 文案

- 先说结论；平常话；名称、按钮、筛选至少两个字；不写口号和教学段落。
- 统一用词：端到端加密 · 联系人 · 群组 · 队友 · 任务 · 进行中 · 已暂停 · 已停止 · 规则 · 最近删除。
- 改写示例：

| 旧 | 新 |
|---|---|
| 你的 AI，和朋友的 AI，一起把事做完 | 个人 AI 工作台，可以和联系人的 AI 协作 |
| 看不到内容 | 端到端加密 |
| 正在读… | 灰条占位，不写字 |
| 在做 | 进行中 |

## 这一版定下的页面

- **导航**：电脑图标栏 首页 · Plasticine · 消息 · 任务 ｜ 网页 · 阅读 ｜ 笔记 · 资料库；手机底栏不变，
  「更多」里是任务、阅读、资料库、设置。
- **首页**：电脑两栏。左边三段：要你处理 → 进行中 → 新的（报告、来信、昨晚整理的记忆）；右边窄栏：今天（日程）、
  接着读（图书进度）、信息流（几条，带「更多」）。手机合成一列，顺序同左栏再接右栏。问候、日期、数量都用真实数据。
- **阅读**：一个入口。第二栏分四段：信息流（带数）、收藏、图书馆（全部图书 + 在读的书）、来源（每个来源一行带数）。
  信息流单列（版心 720），每条：来源头像 + 名称 + 时间 / 标题 / 摘要，配图最高 280；条目平铺、细线分隔。
  手机没有第二栏：页头标题「阅读」，下面分段切信息流和图书馆。
- **抖音收藏**：左右分栏。列表带缩略块（播放符号 + 时长）、整理状态（没整理 / 在整理 / 已整理），分段筛选；可多选后「整理这 n 条」。
  详情：一句话结论、原视频 / 讨论、大纲（时间点 + 小标题）、要点。
- **图书笔记**（资料库 / 图书笔记）：文档页。开头一句话总述，每卷一个小节：卷名、一句摘要、回原文入口；不用色条。
- **队友**：页头头像 + 名字 + 职责，右侧「规则 n」；下面进行中、最近交付。新建队友对话框：名字、颜色（色块）、
  职责、模型（默认跟主线）。
