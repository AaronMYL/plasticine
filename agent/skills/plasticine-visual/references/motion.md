# 动效决策：变化有理由，阅读有稳定感

## 先写意图，再选运动

每个动效先回答：用户需要理解哪一种变化？如果答案只有“显得高级、有生命力”，先不用。

| 意图 | 优先机制 | 避免 |
|---|---|---|
| 确认操作被接收 | 局部按压/状态文字变化 | 整页弹跳、固定延时伪装处理 |
| 展示真实任务状态 | 同一位置的文字与图标过渡 | 假百分比、无意义持续脉冲 |
| 保留对象空间关系 | 短距离移动、尺寸衔接或占位稳定 | 从无关方向飞入、关闭后丢位置 |
| 列表发生增删或重排 | 稳定键与必要的补位过渡 | 阅读中突然重排、每次全列表重播 |
| 进入详情或退出浮层 | 弱透明与小幅空间过渡 | 长距离飞行、正文缩放模糊 |
| 指示新变化 | 有限一次的局部强调 | 永久呼吸、反复闪烁、抢焦点 |
| 纯粹阅读 | 不动 | 逐字扫光、持续漂浮、鼠标磁吸正文 |

弹簧不是默认风格。只有物体响应或直接操控确实受益时，才考虑轻微弹性；正文、表格与精密编辑优先稳定停止，不明显过冲。

## 参数仅为可校准默认

以下数值是本 Skill 提议的起点，非已批准设计 token。方向 I 还没有定动效令牌；1ca0391 的 glass.css 动效参数不沿用。新版第一次定下时长和曲线后写进令牌表，之后都从那里取，一致性比套用某个值重要。Absolute 的取向：能不动就不动，过渡只用透明度和 2–8px 位移，不用缩放和弹性。

| 情境 | 建议时长 | 说明 |
|---|---|---|
| 按压、短状态反馈 | 80–140 ms | 应立即响应输入，时长不是网络等待时间 |
| 小浮层、选中态、局部显隐 | 140–220 ms | 结束位置稳定，退场不阻塞必要操作 |
| 展开、补位、上下文衔接 | 180–280 ms | 内容多不等于动画更长；大布局可取消运动 |
| 装饰性强调 | 默认不设置 | 确有辨认价值时仅有限一次 |

位移可从 2–8 px 的局部变化评估，不把该范围套给真正的拖动距离。进入可用平滑减速，退出可略快；全站共用一两条 easing 曲线，不为每个组件创造新曲线。

悬停浮出的文字标签：160 ms 淡入、不做位移，减少动态效果时即时（已定，10-26 第十二节）。

壳的两种收起（提案）：

- 第二栏 252 ↔ 56（网页窄栏）/ 0（其他栏目）（11-08 已实现）：宽度过渡 `--motion-slow`、`--ease-out`，主区跟着补位；
  里面的东西按展开时的宽度排，只被裁掉、露出来，不在过渡中重排成两行；窄栏换上时内容淡入 + 从左 6px 滑进。
- 对话栏 ↔ 浮动圆球：收起时对话栏淡出、主区补位，圆球在右下淡入；展开反过来。不做「栏缩成球」的飞行变形，滚动位置和草稿在过渡前后不变。
- 窄于 1024 时对话栏从圆球展开浮在主区上：圆球淡出、对话栏从右侧短距离（2–8px）滑入并淡入，140–220 ms。
- 浮层（Sheet）：从右侧短距离（2–8px）滑入并淡入，140–220 ms；遮罩同步淡入；关闭略快。手机底部抽屉从下推上，同样短时长。
- 减少动态效果时以上全部即时切换。

## 状态与中断

- 先保证状态正确，再加过渡。动画结束事件不可成为唯一提交或状态推进信号。
- 快速重复点击、反向切换、导航离开、失败回退时，取消或衔接到当前真实状态，不排队播放过时状态。
- 组件退出时避免提前删除仍被焦点或辅助技术访问的内容；若立即卸载更安全，则取消退场动画。
- 拖动保留用户直接控制，放下后的吸附不改变其目标。不要用弹性移动点击命中区域来“逗”用户。
- 不在用户阅读时通过顶部插入或排序动画改变阅读锚点。先保留位置，再提示可查看变化。
- 颜色过渡不承载唯一状态信息；视觉顺滑不能掩盖失败和待确认。

## 减少动态效果与性能

尊重系统减少动态效果设置。关闭大位移、缩放、弹性、视差、逐字模糊及循环装饰；以即时变化或短淡入替代，并保留状态文字与焦点反馈。

优先局部、可取消的变化。能用 transform/opacity 时避免逐帧重排，但不要为了性能把文字栅格缩放到模糊。需要高度过渡时，评估内容长度与设备成本；直接展开也可以是正确方案。

禁止在卸载后保留计时器、观察器或动画循环。不要为单个微交互引入重量级依赖，除非项目已有并适用，或新增依赖经过明确选择。

## 动效小规格

针对复杂组件，用以下短规格而非只写“加点高级动画”：

- 变化对象与用户意图。
- 触发条件、真实起始/终止状态。
- 保持不变的阅读锚点、焦点、草稿或命中区域。
- 运动方式、沿用或建议的 token。
- 快速打断、逆向、失败与离开时的处理。
- 减少动态效果替代。
- 用户能观察到的通过条件。
